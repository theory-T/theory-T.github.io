## 一、三种模式

1. **普通模式**：打开文件后默认进入，用于移动光标、删除、复制、粘贴，按 `Esc` 返回
2. **插入模式**：按 `i`（光标前）、`a`（光标后）、`o`（下一行）进入，用于输入文本
3. **底行模式**：按 `:` 进入，执行 `:w` 保存、`:q` 退出、`:wq` 保存退出、`:q!` 强制退出

## 二、常用命令

| 命令 | 作用 |
|------|------|
| `dd` | 删除整行 |
| `yy` | 复制当前行 |
| `p` | 粘贴 |
| `u` | 撤销 |
| `/word` | 向下查找 |
| `:%s/old/new/g` | 全文替换 |
| `:set nu` | 显示行号 |
